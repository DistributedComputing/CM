\begin{frame}[fragile]{2 -- Limite de \lstinline{getAndIncrement}}

    \vspace{-3mm}
  \begin{exampleblock}{Lemme}
    \begin{itemize}
    \item Il est impossible de résoudre le consensus entre 3 processus à partir de \lstinline{getAndIncrement}
    \end{itemize}
  \end{exampleblock}

    \vspace{-3mm}
  \begin{block}{Démonstration}
    Même structure que pour l'impossibilité du consensus à partir de lire/écrire : 
    \begin{description}
    \item[Introduction] Supposons qu'il existe un tel algorithme $A$ ; \structure{(idem)}
    \item[Lemme 1] $A$ possède une configuration critique ; \structure{(idem)}
    \item[Lemme 2] $A$ ne possède pas de configuration critique ; \structure{(à adapter)}
      \begin{itemize}
      \item l'un d'eux lit, écrit ou accède un autre registre \structure{(idem)}
      \item les trois appellent \lstinline{getAndIncrement} sur le même registre
      \end{itemize}
    \end{description}
