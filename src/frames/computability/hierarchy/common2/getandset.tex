\begin{frame}[fragile]{Calculabilité de \lstinline{getAndSet}}

  \begin{alertblock}{Théorème}
    \begin{itemize}
    \item \lstinline{getAndSet} résout le consensus entre 2 threads
    \item \lstinline{getAndSet} ne résout pas le consensus entre $\ge 3$ threads
    \end{itemize}
  \end{alertblock}

  \begin{block}{Démonstration}
    Supposons qu'il existe un protocole pour 3 threads. Dans un état critique:
    \begin{itemize}
    \item si l'un d'eux lit, écrit ou accède à un registre différent : comme avant
    \item si les trois appellent \lstinline{getAndSet}
    \end{itemize}
